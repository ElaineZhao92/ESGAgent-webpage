# ESGAgent

Project page for **"Advancing ESG Intelligence: An Expert-Level Agent and Comprehensive Benchmark for Sustainable Finance"**, accepted at **EMNLP 2026**.

ESGAgent introduces an expert-level agent for ESG (Environmental, Social, and Governance) analysis in sustainable finance, together with a comprehensive benchmark for evaluating such agents.

**Authors:** Yilei Zhao, Wentao Zhang, Lei Xiao, Yandan Zheng, Mengpu Liu, Wei Yang Bryan Lim
**Affiliations:** Nanyang Technological University, Alibaba Group

Live page: https://elainezhao92.github.io/ESGAgent-webpage/
